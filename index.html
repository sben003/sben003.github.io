Projet phare

Conçu et mis en production seul

Supervision environnementale marine

Vigie Océan

Stage de fin de M1 · UPPA Tech, plateau SCOPE
Avril – juillet 2026 · Côte basque

Une plateforme qui va de la sonde immergée jusqu'à l'interface de consultation : ingestion des fichiers bruts, normalisation de trois formats fournisseurs, contrôle qualité, stockage en série temporelle, API et visualisation. J'ai conçu, développé et mis en production l'ensemble de la chaîne.

~1,7 M
Stockage

Réponse API
< 50 ms
Tests d'intégration

01Ingestion

Des sondes multiparamètres connectées en 3G/4G déposent leurs fichiers sur un serveur FTP. Le réseau de l'université bloquait les connexions entrantes : j'ai monté une VM sur Google Cloud et un service Python qui rapatrie les fichiers toutes les 15 minutes.

  • Python
  • ftplib
  • APScheduler
  • Google Cloud Platform
  • FTP

02Normalisation

Trois fournisseurs, trois formats CSV différents. Un parser dédié par format, un routeur qui détecte automatiquement le format d'un fichier entrant, et une table de correspondance qui unifie les paramètres physico-chimiques dans un référentiel unique.

  • Python
  • Pandas
  • CSV

03Contrôle qualité

Chaque mesure passe une série de contrôles avant intégration : valeurs manquantes, doublons, bornes physiques, valeurs aberrantes. Environ 1,7 million de mesures traitées. Une mesure écartée est mise de côté de façon réversible plutôt que supprimée — la décision reste annulable.

  • Python
  • Pandas

04Stockage

Les séries temporelles sont stockées dans une hypertable TimescaleDB partitionnée. La compression columnaire ramène 460 Mo à 27 Mo.

  • TimescaleDB
  • PostgreSQL
  • SQL

05API

Un backend FastAPI répond sous les 50 millisecondes. Normalisation stricte des horodatages en UTC et exports Excel horodatés.

  • FastAPI
  • Python
  • REST

06Interface

Frontend React / TypeScript. Un sous-échantillonnage LTTB garde un rendu fluide au zoom, et les séries sont synchronisées avec les prédictions de marée.

  • React
  • TypeScript

07Fiabilité & exploitation

14 tests d'intégration Pytest, sauvegardes quotidiennes par cron, et un déploiement complet sous Docker Compose.

  • Pytest
  • Docker Compose
  • cron
  • Linux
