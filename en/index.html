The problem

Oceanographic probes ship with their manufacturer’s proprietary cloud subscription. For a laboratory running several brands, readings fragment into incompatible silos and the budget keeps paying recurring fees.

The answer

A self-hosted platform in seven Docker containers: a parser registry that recognises each format by reading the file’s contents, a compressed TimescaleDB hypertable, a FastAPI backend, and a React interface where every correction stays reversible.

Methods & practice

What gets a piece of work into production, and keeps it there.

Short, shippable iterations
Five successive increments on Vigie Océan, each closed by a real deployment rather than a frozen plan.
Explicit interface contracts
File format, relational schema, REST contract: every boundary between services is specified and stable.
Acceptance testing in real conditions
Status codes, latencies, integrity of generated files — checked against production, not just locally.
Reversible decisions
Logical deletion rather than destruction, idempotent ingestion, automated daily backups.
Operations documentation
Recovery guide, restore procedure, user manual — so the project outlives whoever wrote it.
Modelling before code
UML on the HR application, star schema on the data warehouse, dimensional model before the cubes.
