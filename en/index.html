01Ingestion

Multiparameter probes connected over 3G/4G drop their files onto an FTP server. The university network blocked inbound connections, so I set up a VM on Google Cloud running a Python service that pulls the files every 15 minutes.

  • Python
  • ftplib
  • APScheduler
  • Google Cloud Platform
  • FTP

02Normalisation

Three vendors, three different CSV formats. A dedicated parser per format, a router that automatically detects the format of an incoming file, and a mapping table that unifies the physico-chemical parameters into a single reference model.

  • Python
  • Pandas
  • CSV

03Quality control

Every measurement goes through a series of checks before it is stored: missing values, duplicates, physical bounds, outliers. Around 1.7 million measurements processed. A rejected measurement is set aside reversibly rather than deleted — the decision can be undone.

  • Python
  • Pandas

04Storage

Time series are stored in a partitioned TimescaleDB hypertable. Columnar compression brings 460 MB down to 27 MB.

  • TimescaleDB
  • PostgreSQL
  • SQL

05API

A FastAPI backend answers in under 50 milliseconds. Strict UTC timestamp normalisation and timestamped Excel exports.

  • FastAPI
  • Python
  • REST

06Interface

A React / TypeScript frontend. LTTB downsampling keeps rendering smooth while zooming, and the series are synchronised with tide forecasts.

  • React
  • TypeScript

07Reliability & operations

14 Pytest integration tests, daily backups via cron, and a full deployment under Docker Compose.

  • Pytest
  • Docker Compose
